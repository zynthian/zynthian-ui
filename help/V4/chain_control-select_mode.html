Select Mode

When in select mode you can:

  • browse list at right (parameter pages or any other) by rotating knob 4
  • browse chain-blocks panel (shown at left) by rotating knob 3

To exit select mode simply push short+BACK.

The blocks available in the left panel depend of the chain type and processors:

  • Chain Options
  • MIDI Input
  • Audio Input
  • MIDI Processors
  • Synth Processor
  • Audio Processors
  • MIDI Output
  • Audio Output

Processor Blocks

When a processor is selected, the page list is repositioned to show the processor pages. You can access the processor options with short+knob 3 or short+OPT.

Non-Procesor Blocks

When a non-processor block is selected, like Chain Options, MIDI Input, Audio Input, etc. you will see a configuration panel. You can navigate the options by rotating knob 4 and select/check options with short+knob 4. Alternately you can use UP/DOWN and SELECT buttons. If the option has suboptions, you can access the suboptions menu with bold+knob 4, bold+SELECT or short+OPT.
