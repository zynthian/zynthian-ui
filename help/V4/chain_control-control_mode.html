Control Mode

When in control mode you can:

  • Modify the value of processor parameters by rotating the knobs.
  • Enter MIDI learn mode by short-pushing knob#3.

Processor parameters are grouped in pages of 4. You can move across the list using the S3 / S4 buttons. The list contains the control pages for all processors in the chain. To move across the pages, enter select mode with short+SELECT or short+OPT.

MIDI Learn

You can bind any parameter to knobs, faders and CC-pads from your MIDI controllers. There are 2 different MIDI learn modes:

  • Chain Learn (short+knob#3): Binding is relative to the selected chain. You can bind the same knob to one or several parameters in the same or different chains. Only the selected chain will react to the knob rotation. Displayed in green
  • Global Learn (short+knob#3 twice): The bind is global. You can bind the same knob to one or several parameters in the same or different chains. All of them will react, not matter the selected chain. Displayed in yellow.
The MIDI learn procedure is:
  • short+knob#3 once to enter chain MIDI learn or twice to enter global MIDI learn.
  • rotate knob associated to the parameter you want to learn. "??#??" will be displayed in green or yellow depending of the MIDI learn mode.
  • move a knob/fader or push a CC-pad in your MIDI controller. The binding is complete and the little green/yellow text now shows then MIDI channel and CC number

While in MIDI learn mode, you can access the parameter control options by bold-pushing the knobs.

You can cancel MIDI learn at any moment by pushing back.

Parameter control options

While in MIDI learn mode, bold-push any knob to access the controller options for the associated parameter:

  • Chain Controller: When checked, the parameter is added to the chain controller pages, at the beginning of the page list. This feature acts as a kind of "favorite parameters" for the chain.
  • X-Y touchpad: When numeric parameters have been selected for X and Y axis, "Show Touchpad" option is available and you can X-Y control both parameters at once using your finger "a la chaos-pad".
  • Absolute/Relative Mode: Allows to configure incremental knobs (encoders).
  • CC Value Range: Configure how MIDI CC values are mapped to the associated parameter.
  • Chain Learn: Start Chain MIDI learn for the parameter.
  • Global Learn: Start Global MIDI learn for the parameter.
  • Zynstep CC: Choose the CC number used by the sequencer to automate the parameter.
  • Unlearn: Unlearn the parameter.
  • Unlearn all controls: Unlearn all parameters in the engine.
