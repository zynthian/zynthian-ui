Chain Config View

The chain config view, also known as select mode, allows to configure every aspect in a chain.

The left side panel contains the list of blocks that configure your chain, including the processors.The right panel shows a reduced version of the chain control view. Use knob 3 to browse the left-hand chain blocks and knob 4 to browse the right-hand list.

To exit simply short press BACK which returns to the chain control view.

The chain blocks in the left panel act similarly to the chain manager view and depend on the chain type and processors. They may be:

  • Chain Options
  • MIDI Input
  • Audio Input
  • MIDI Processors
  • Synth Processor
  • Audio Processors
  • MIDI Output
  • Audio Output

Processor Blocks

When a processor is selected, the right-hand list is repositioned to show the parameter pages for that processor. You can access the processor options with short press knob 3 or a second tap on the block on a touchscreen.

Non-Processor Blocks

When a non-processor block is selected, like Chain Options, MIDI Input, etc. a configuration panel is displayed in the right-hand panel. You can navigate the options by rotating knob 4 and select/check options with short press knob 4. If the option has sub-options, you can access the sub-options menu with bold press knob 4.
