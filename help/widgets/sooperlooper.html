SooperLooper

Single Pedal Mode

You can drive SooperLooper with a single MIDI pedal. This is achieved by binding the pedal that sends a MIDI CC message to the "single pedal" controller that is found on the "Global loop" (6th) page of controls. Zynthian expects a non-zero CC value when the pedal is pressed and a zero value when released. The following actions are available:

  • Press when idle, e.g. first press will start recording the loop.
  • Press when recording will stop recording and start playing the loop.
  • Press when playing will start overdubbing the loop.
  • Double press whilst playing will pause the loop.
  • Triple press will clear the loop.
  • Double press and hold will clear the loop.
  • Single press and hold will record or overdub until the pedal is released.

MIDI CC to selected loop

Any encoder acts on the currently selected loop. And any MIDI binding you create will also act on the currently selected loop. This is reflected by the control "MIDI CC to selected loop", on the last page of controllers being by default set to "on".

However, if you set this control to "off", creating a MIDI binding will bind the CC to the loop selected at that time. The controls affected by this show the current loop number within parentheses.

This binding will stay bound to that loop, even if you select another loop. That way, you can have multiple pedals designated to specific loops.

NOTE that the control needs to be in the "off" state for enacting the loop-bound MIDI binding, and in the "on" state for the 'selected loop'-mode bindings to work

ALT mode

SooperLooper has it's own local Alt Mode. This redefines the short-push functionality of transport, arrows and F1-F4 buttons:

NOTE: MIDI-CC to selected loop described above should be set to "on" for these to work

  • REC
    • on empty loop:toggles recording in the selected loop
    • on busy loop: toggles overdubbing in the selected loop
  • PLAY toggles mute the selected loop
  • STOP toggles multiplying the selected loop
  • F1 toggles replacing in the selected loop
  • F2 toggles substituting in the selected loop
  • F3 toggles inserting in the selected loop
  • F4 adds a new empty loop
  • LEFT undo the last operation in the selected loop
  • RIGHT redo the last operation in the selected loop
  • UP/DOWN changes the selected loop
