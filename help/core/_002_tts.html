Narrator text-to-speech

Zynthian has a rich, text-to-speech user interface called, Narrator that allows full control using the hardware buttons and knobs with audible cues for guidance. Navigation and operation is assisted by spoken announcements and tones. Narrator uses an extra audio interface or soundcard to provide an audio output separate to the main output. This gives a clean audio for production with Narrator announcements feeding the user's personal monitoring.

Getting Started

Add an audio device for Narrator to use, for example: plug in a USB soundcard. This does not need to be an expensive, hi-fidelity device. A $2 device has been found to be sufficient.

Remember these terms:

  • Press means to briefly press and release a button.
  • Bold press means to press a button for about 1.5 seconds and then release.
  • Long press means to press and hold a button for at least 2 seconds.

By default, Narrator is disabled but it is very simple to enable by a long press of the F4 button. On a zynthian V5, this button is at the bottom right of the 20 button keypad. On a zynthian V4 it is at the right of the centre 4 buttons. This action toggles Narrator between enabled and disabled. When you enable Narrator you should hear an announcement saying, Narrator enabled. Similarly when you disable Narrator you should hear an announcement saying, Narrator disabled.

When Narrator is enabled, you will hear announcements as you navigate the user interface and perform actions, for example: as you enter a view its name will be announced so that you have an indication of where you are in the navigation tree. When you move through lists, each list item is announced.

There is a short delay of about 0.2 seconds before each announcement. Announcements may be queued if necessary but are mostly interrupted by the most recent, for example: moving through a list may skip intermediate items.

The F4 button acts as the Narrator button. It may be used to stop the current announcements. If Narrator is silent, the Narrator button will trigger a context announcement. By default this is the name of the current view but may also include some context for that view, for example: it may tell you the highlighted entry in a list. A long press of the Narrator button will toggle Narrator enable.

As well as spoken announcements, Narrator will pulse a short tone every second whilst the user interface is busy, for example: when loading a snapshot. The end of the busy period is indicated with a longer, higher pitched tone.

Bold press the ALT button to access the help view. Narrator will start to read out the help information for the current view. Knob 3 assists the help reader. Pressing knob 3 will toggle pause, stopping playback or resuming from the start of the current sentence. Rotating knob 3 will select the previous or next sentence. Bold pressing knob 3 will announce the actions for the knobs in this view, including their rotation, press, and bold press actions. The Navigator button may be used to stop or restart from the beginning of the page. Press knob 4 to toggle hyperlink mode. Rotate knob 4 to select a link then press knob 4 to follow the link. Press back to exit link mode. The first link on each page is to an index of all available help pages and a press of knob 4 will access this index if there are no other links on the page.

Some views are lists of options with additional information available for each entry. By default, only the title of the list entry is announced. Pressing the narrator button may read out this extra information. There may not be dedicated help pages for these views as they are fairly self-explanatory.
