Selector Grid View

The selector grid view is used to show a grid of selectable options. Selecting an entry may toggle a value, open the parameter editor or navigate to another view. Use knob 4 to browse the list and press to select the item. There may be alternative actions available with bold or long press. Use BACK to exit the view.

Each grid node has an image and title. This may be sufficient to avoid the need for a dedicated help page, hence why you are seeing this generic page.
