Chain Control View

The chain control view provides access to the parameters of the processors in the active chain. You can:

  • Modify the value of processor parameters by rotating the knobs.
  • MIDI learn parameters by short pressing the knobs
  • Configure parameter control options by bold pressing the knobs.

Processor parameters are grouped in pages with up to 4 parameters per page. Select pages using the UP / DOWN buttons. The list contains the control pages for all processors in the chain.

To move faster across the pages, enter select mode with:

  • short press SELECT
    • or
  • short press OPT

Note that select mode is also known as the chain config view.

MIDI Learn

You can bind any parameter to knobs, faders and CC-pads on your external MIDI controllers. There are 2 different MIDI learn modes:

  • Chain Learn: Binding is only to the selected chain. You can bind the same knob to one or several parameters in the same or different chains. Only the selected chain will react to the MIDI CC message.
  • Global Learn: The bind is global. You can bind the same knob to one or several parameters in the same or different chains. All of them will react, no matter the selected chain.
The MIDI learn procedure is:
  • short press the knob associated with the parameter you want to learn. A green indication ??#?? will be displayed indicating the parameter is in chain learning mode.
  • if required, short press again to enter global learning mode. The indication will change to yellow: ??#??.
  • move a knob/fader or tap a CC-pad on your external MIDI controller. The binding is complete and the indication now shows then MIDI channel and CC number in white.

Parameter control options

Bold press any knob to access the controller options for the associated parameter:

  • Chain Controller: When checked, the parameter is added to the chain controller pages, at the beginning of the page list. This feature acts as a kind of "favorite parameters" for the chain.
  • X-Y touchpad: When numeric parameters have been selected for X and Y axis, "Show Touchpad" option is available and you can X-Y control both parameters at once using your finger "a la chaos-pad".
  • Absolute/Relative Mode: Allows to configure incremental knobs (encoders).
  • CC Value Range: Configure how MIDI CC values are mapped to the associated parameter.
  • Chain Learn: Start Chain MIDI learn for the parameter.
  • Global Learn: Start Global MIDI learn for the parameter.
  • Zynstep CC: Choose the CC number used by the sequencer to automate the parameter.
  • Unlearn: Unlearn the parameter.
  • Unlearn all controls: Unlearn all parameters in the processor.
