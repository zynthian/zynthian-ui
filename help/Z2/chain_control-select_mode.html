Control View: Select Mode

The control view provides access to the parameters of a processor. When in select mode there is a left panel that contains a list of processors in the chain and a right panel that shows the view for the selected processor. Use knob 3 to browse the left-hand chain blocks and knob 4 to browse the right-hand list.

To exit select mode simply short press BACK which returns to control mode.

The chain blocks in the left panel act similarly to the chain manager view. and depend on the chain type and processors. They may be:

  • Chain Options
  • MIDI Input
  • Audio Input
  • MIDI Processors
  • Synth Processor
  • Audio Processors
  • MIDI Output
  • Audio Output

Processor Blocks

When a processor is selected, the right-hand list is repositioned to show the parameter pages for that processor. You can access the processor options with short press knob 3 or short press OPT.

Non-Processor Blocks

When a non-processor block is selected, like Chain Options, MIDI Input, etc. a configuration panel is displayed in the right-hand panel. You can navigate the options by rotating knob 4 and select/check options with short press knob 4. Alternately you can use UP/DOWN and SELECT buttons. If the option has sub-options, you can access the sub-options menu with bold press knob 4, bold press SELECT or short press OPT.
