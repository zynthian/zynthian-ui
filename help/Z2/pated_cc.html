Pattern CC Editor

The launcher is the zynthian's sequencer main view. You can always access the launcher by pushing the PAD button. You can also push BACK repeatedly until reaching it.

From the mixer, you can access the launcher by pushing BACK. Similarly, from the launcher, you can access the mixer by pushing BACK. Launcher and Mixer are, indeed, a single view with 2 modes.

The launcher is a grid where columns match mixer's strips. Rows are called "phrases", being quite similar to Ableton Live's "scenes". Chain columns contain sequencer patterns or audio clips. The main column contains phrase launchers.

Initially the grid will be empty, showing the main strip alone. When adding a chain, a new column is added to the grid. When deleting a chain, the associated grid column will be removed. Note the associated patterns are not deleted. They are associated with the MIDI channel and if you create a new chain with the same MIDI channel, the removed patterns will be available again.

Short-push on any cell to play/stop the associated sequence, audio clip or launch a phrase.

Push STEP or Bold-push to edit the selected sequence or audio clip. If the cell contains a sequence, the pattern editor will be opened, if the cell contains an audio clip, the audio clip control view.

Push STEP or Bold-push on a phrase launcher (main column) to open the phrase options and configure the phrase parameters and manage phrases.

The phrase parameters are:

  • Duration: Number of bars. By default, it takes the value from the longer sequence in the row
  • Tempo: When the phrase is launched, the tempo is changed to the specified value in BPM.
  • Beats per Bar: The time signature used in patterns.
  • Automate: "Loop from", "loops to play" and "jump to" options allow to create simple song structures.
