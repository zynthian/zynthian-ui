Pattern Note Editor

The pattern note editor allows to add/remove notes in a pattern and modify the note parameters. The contextual menu (OPT) allows modifying all the pattern parameters.

The PLAY/STOP buttons can be used to play/stop the pattern. The REC button allows enabling live-recording to capture MIDI events in real-time.

The ALT mode allows accessing special functionality like undo/redo, block operations, copy/past patterns.

Basic Operation

Rotate knobs 3 & 4 to move the cursor vertical or horizontally. With ALT mode disabled, arrow buttons can be used for this too.

Short-push knob 4 to add/remove notes. Bold-push knob 4 to edit note parameters. Alternately, SEL button can be used for this too.

Rotate knob 2 to adjust the zoom in and out. Short-push knob 2 to reset zoom to the default value.

Short-push knob 3 to enter block selection. The block operation workflow is explained in detail in the section below.

Short-push OPT button to open the pattern options menu that allows modifying all pattern parameters. To quickly change the pattern length you can bold-push knob 2.

Finally, short-push knob 1 to swap the note & CC editors.

Recording Patterns

Push REC button to enable MIDI recording. While record is armed, the REC button will light with red color.

Step by Step Capture

If the pattern is not playing (stopped), note events will be captured in the cursor position, moving the cursor to the next step. You can use the sustain pedal to advance step by step.

Live Capture

If the pattern is playing, note and CC events are captured in real time. They are recorded at the exact time they are captured, without quantization. If desired, quantization can be applied to replaying (see pattern options menu). While live capturing, history is saved on each pattern loop if new notes were captured.

Undo/Redo

In ALT mode, you can use the arrow keys to undo/redo:

  • LEFT: Undo last edit operation.
  • RIGHT: Redo last undone operation.
  • DOWN: Undo ALL.
  • UP:Redo ALL.

While record is armed (REC button lighting in red), bold-push BACK button to enter history navigation mode. Then you can rotate knob 4 to move along the history. Push BACK to exit.

Note that although the number of history steps is unlimited, history is not saved in the state and will be lost when loading the snapshot again.
