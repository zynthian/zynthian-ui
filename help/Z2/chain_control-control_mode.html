Control Mode

When in control mode you can:

  • Modify the value of processor parameters by rotating the knobs.
  • MIDI learn parameters by short-pushing the knobs
  • Access parameter control options by bold-pushing the knobs.

Processor parameters are grouped in pages of 4. You can move across the list using the UP / DOWN buttons. The list contains the control pages for all processors in the chain. To move faster across the pages, enter select mode with short+SELECT or short+OPT.

MIDI Learn

You can bind any parameter to knobs, faders and CC-pads from your MIDI controllers. There are 2 different MIDI learn modes:

Chain Learn: Binding is relative to the selected chain. You can bind the same knob to one or several parameters in the same or different chains. Only the selected chain will react to the knob rotation.

  • short-push the knob associated to the parameter you want to learn. A little green "??#??" will be displayed.
  • move a knob/fader or push a CC-pad in your MIDI controller. The binding is complete and the little green text now shows then MIDI channel and CC number

Global Learn: The bind is global. You can bind the same knob to one or several parameters in the same or different chains. All of them will react, not matter the selected chain.

  • short-push twice the knob associated to the parameter you want to learn. A little yellow "??#??" will be displayed.
  • move a knob/fader or push a CC-pad in your MIDI controller. The binding is complete and the little yellow text now shows then MIDI channel and CC number

Parameter control options

Bold-push on any knob to access the controller options for the associated parameter:

  • Chain Controller: When checked, the parameter is added to the chain controller pages, at the beginning of the page list. This feature acts as a kind of "favorite parameters" for the chain.
  • X-Y touchpad: When numeric parameters have been selected for X and Y axis, "Show Touchpad" option is available and you can X-Y control both parameters at once using your finger "a la chaos-pad".
  • Absolute/Relative Mode: Allows to configure incremental knobs (encoders).
  • CC Value Range: Configure how MIDI CC values are mapped to the associated parameter.
  • Chain Learn: Start Chain MIDI learn for the parameter.
  • Global Learn: Start Global MIDI learn for the parameter.
  • Zynstep CC: Choose the CC number used by the sequencer to automate the parameter.
  • Unlearn: Unlearn the parameter.
  • Unlearn all controls: Unlearn all parameters in the engine.
